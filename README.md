
# Sales Performance Dashboard (Excel)

An interactive Excel dashboard analyzing sales, profit, and customer behavior.



## Business Questions
- Which brand, location, and age group are the most profitable?
- Who are the top customers and top sales person?
- How does revenue vary by payment method, gender, and price range?

## Key Metrics
- Total Revenue: $5.67M
- Total Profit: $2.38M
- Profit Margin: 41.96%
- Quantity Sold: 284,455

## Key Insights
- Most profitable brand: Shortbread
- Most profitable location: San Antonio
- Top sales person: Travis Doyle
- Most profitable age group: 60-74

## Tools Used
- Excel: Pivot Tables, Pivot Charts, Slicers,Switch Function
